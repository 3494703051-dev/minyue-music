DESIGN SPEC · v1

民族音乐 · 四大民族 UI 主题设计稿

依据各民族的图腾信仰、传统服饰色制、织物纹样与代表性乐器，为畲族 / 塔吉克族 / 怒族 / 鄂温克族各设计一套界面皮肤。四套皮肤共用同一套骨架（侧栏 · 顶栏 · 歌单头 · 曲目表 · 播放条），只替换配色、纹样与图腾标识——落地时对应现有模板 :root 里的几个变量即可，不需要改动布局结构。

先给你过目，尚未动 dmg。确认方向后我再改 mountainriverechoes.html 并重新打包。本页左上角为设计依据，左下为 UI 实景预览，底部为变量落地清单。
01

畲族 · 凤凰装

凤凰图腾 · 三公主与盘瓠传说 —— 以「崇凤」立色的民族
凤凰图腾彩带 · 合手巾带三月三乌饭节高皇歌畲歌对唱

设计依据

  • 图腾是凤凰：相传三公主出嫁着凤冠凤衣，畲族女子一律以凤凰装为盛装，故以凤为族徽。
  • 凤凰装色制：红头绳高盘为凤头 · 大红桃红杏黄镶绣为凤颈腰羽 · 金色腰带为凤尾 · 银饰叮当为凤鸣——整首配色诗可以直接翻译成界面层级。
  • 衣裙底色以自织苎麻的黑、蓝为主（黑色居多），彩色花边只作锁边点缀，故界面取深藏青为底、彩色为点缀，而非通体大红。
  • 腰间彩带（合手巾带，宽约四厘米、长逾一米）是定情信物，纹样为柳条与几何织纹 → 用作页面横幅底纹。

02

塔吉克族 · 雄鹰

鹰是精神图腾 —— 帕米尔高原上，「鹰舞」是身体的音乐，「鹰笛」是音乐的翅膀
鹰图腾鹰笛「纳依」鹰舞 · 恰甫苏孜慕士塔格雪山石头城

设计依据

  • 鹰是塔吉克族精神图腾：鹰舞模仿雄鹰盘旋展翅，鹰笛（纳依）以鹰翅骨制三孔短笛，是鹰舞的灵魂伴奏 → 鹰 = 品牌标识 + 播放按钮。
  • 重要色忌：塔吉克习俗中红、黄、白为吉祥色，天蓝与绿色表示不吉利。所以这套主题刻意不采用「高原蓝＋草原绿」，走红白黑金的暖色系——这也是它和另外三套最容易区分的地方。
  • 女性盛装：库勒塔绣花圆帽垂银链「斯力斯拉」，胸前大圆银饰「阿勒卡」象征太阳与月亮；红、紫绣花连衣长裙。此处取「红底 + 圆形银饰」的构图 → 圆形唱片／封面做成银环。
  • 男子吐马克帽为黑绒底、帽檐蓝色丝绒边 → 黑色作稳重的中性色，蓝色只留极细的一道边。
  • 刺绣纹样：雪莲、鹰翅纹、太阳花。

03

怒族 · 怒毯

怒江大峡谷 · 达比亚四弦琴与《哦得得》—— 以「织物」自身作为视觉母题的民族
达比亚四弦琴哦得得怒毯「约多」仙女节 · 鲜花节千脚落地房

设计依据

  • 怒族的图腾遗存集中在纹样上：传统怒毯与挂包图案呈条纹状虎纹，妇女黑腰围取崇尚黑熊之色，笛身刻条纹状、锯齿状图案。（学界亦指出怒族「有图腾现象而少图腾崇拜」，图腾多作氏族标志——设计上因此不强调单一神兽，而以纹样叙事。）
  • 怒毯（约多）是核心视觉：以白色为经、纬线为白，经线可配色，成品为竖条彩纹 → 直接用作页面横幅底纹与卡片纹理，这是四套主题里辨识度最高的一个。
  • 服饰本色是自织麻布（白底间黑线），配红藤缠头、珊瑚／玛瑙／贝壳／银币珠饰 → 底色取麻布米白而非纯白，中性色取怒江墨。
  • 乐器达比亚（怒苏语，四弦琵琶，有梯形与椭圆两种）→ 作为家族标识与播放按钮图形；民歌《哦得得》是族群记忆的载体。

鄂温克族 · 驯鹿森林

「住在大山中的人」· 使鹿部落与白桦林 —— 驯鹿是「森林之舟」，熊是祖先图腾
驯鹿 · 森林之舟熊图腾白桦树皮烫纹撮罗子大兴安岭

设计依据

  • 族名本义即「住在大山中的人」，故整套主题以大兴安岭针叶林的深绿为底，不是草原色。
  • 双重图腾：熊为祖先图腾（猎熊要行风葬、敬烟，且忌直呼其名，称「阿玛哈」舅舅）；驯鹿被视为吉祥、幸福、进取的象征，萨满神帽即为双鹿角造型。视觉上以鹿为主形象——熊的形象过于沉重，不适合做界面符号。
  • 手工艺核心是桦树皮制作技艺（国家级非遗）：在白桦皮上用烧红的铁线烫出黑色纹样，再以红、蓝点缀，染料取自植物，主色即红、蓝、黑 → 天然就是一套 UI 配色。
  • 服饰细节：敖鲁古雅妇女连衣裙加白、黑、红三色领边；男子帽为圆锥形、顶尖红缨穗、多以蓝布为面 → 红作强调、蓝作次强调，白／桦皮色作纸面。
  • 动物纹以鹿纹、马纹最常用；居住为圆锥形「撮罗子」（夏覆桦皮、冬盖兽皮）→ 可用作卡片剪影与波形纹。

四套主题一览

民族主题名核心符号主色 / 强调色一句话气质
畲族 凤凰装 凤凰 · 彩带 #16273d 藏青 / #b8121f 凤凰红 深青底上绣彩——庄重里透出热闹，像一身凤凰装。

沿用现状：其余民族（汉族民间小调等）保持原有金色／红色默认皮肤不变。切换方式建议——打开某民族歌单时自动套用对应皮肤，也可在「音源设置」里手动锁定。
