四大民族歌单 插画封面 设计稿

上一版的封面是「两色渐变 + 族名文字」，四个民族只有色相差别。这一版把封面升级成**完整的场景插画**：每个民族一张画，有远、中、近景层次，有该民族独有的图腾与器物，不看字也能认出来是哪个民族。

全部为纯内联 SVG，不依赖网络、不增加二进制资源——这对冻结打包的 .app 很关键：图片随模板一起进包，离线可用、任意尺寸不失真、体积只有几 KB。尚未修改 dmg。

畲族 · 凤凰与山 · 320×320 纯 SVG

凤凰与山 畲族 · 崇凤民族

构图逻辑：竖向上的三层山峦 + 横向飘过的一条彩带 + 居中展翅的凤凰 —— 「山」是畲族的居住环境，「带」是定情的彩带，「凤」是图腾。

画面构成

暮色天幕（藏青渐变）星点与月三层山峦剪影畲寨坡屋顶金色展翅凤凰（主体）红黄桃粉绿彩带（前景）金色凤冠

为什么只能是畲族

彩带（合手巾带）是畲族特有的定情信物——宽约四厘米、长一米余、自织，纹样为柳条与几何织纹。画面中那条横穿的彩带是唯一以"织物"作为前景装饰的民族母题，与塔吉克的刺绣带、怒毯的竖条、桦皮的横纹都不同。

鹰与慕士塔格 塔吉克族 · 鹰之族

构图逻辑：金字塔形雪峰立于正中 + 峰后一轮金色太阳 + 高空一只盘旋的鹰 + 山脚石头城与毡房 + 底部太阳花刺绣带。四张封面里唯一「对称式山体构图」。

画面构成

高原日出天空（红→金）三重太阳光环盘旋的鹰（剪影）慕士塔格峰（白雪 + 阴影面）石头城残墙毡房底部太阳花刺绣带

为什么只能是塔吉克族

慕士塔格峰（冰山之父）+ 石头城是塔什库尔干独有的地标组合；底部的太阳花刺绣带来自塔吉克女性库勒塔帽的刺绣纹样。且整套配色为红 / 金 / 白 / 黑绒——刻意不出现大面积蓝绿，因为天蓝与绿在该族习俗中表示不吉利。

怒族 · 怒江峡谷 · 320×320 纯 SVG

怒江峡谷 怒族 · 峡谷与怒毯

构图逻辑：V 形峡谷夹一条怒江 + 顶部一线天光 + 一根横跨峡谷的溜索 + 山腰千脚落地房 + 岩壁上露出怒毯竖条彩纹。四张封面里唯一「垂直纵深构图」。

画面构成

一线天光左右 V 形岩壁岩壁上的怒毯竖条彩纹怒江水流横跨峡谷的溜索（带行人）山腰千脚落地房前景达比亚四弦琴底部怒毯彩带

为什么只能是怒族

怒毯（约多）的竖条彩纹被直接画在两侧岩壁上——这是四套里唯一把织物纹样当地貌纹理用的设计。加上溜索（怒江峡谷标志性交通工具）与千脚落地房（干栏式双层木竹结构），任何一张缩略图都能锁定这是怒族。

鄂温克族 · 白桦林驯鹿 · 320×320 纯 SVG

白桦林驯鹿 鄂温克族 · 住在大山中的人

构图逻辑：竖直的白桦树干作为视觉框架 + 苔藓雪地 + 林间一头带大角的驯鹿 + 远处针叶林 + 圆锥撮罗子。四张封面里唯一「垂直树干框架构图」。

画面构成

森林天光（深绿渐变）斜射阳光束远处针叶林剪影三棵白桦树（白干黑斑）苔藓雪地林间驯鹿（大鹿角 + 红缨项圈）圆锥撮罗子

为什么只能是鄂温克族

白桦树皮的黑斑纹理是鄂温克族桦树皮制作技艺（国家级非遗）的视觉指纹——该族用烧红的铁线在桦皮上烫出黑纹，再以红、蓝点缀。画面中的树干黑斑正是这一工艺的转译；加上带大鹿角的驯鹿与圆锥撮罗子，民族识别度最高。

落地方式（确认设计后执行）

改一个函数即可：模板第 2314 行的 ethCardHTML(g)。现在封面 div 是渐变：

const grad = ETH_COLORS[g.ci % ETH_COLORS.length];
const gs = [mixWhite(grad[0], .68), mixWhite(grad[1], .68)];
return `<div class="pl-card eth-card" data-k="${g.key}" data-nm="${esc(g.name)}">
  <div class="cov" style="background:linear-gradient(135deg,${gs[0]},${gs[1]});color:${grad[0]}">${esc(g.name)}...</div>
  ...`;

改成按 g.key 取对应的插画 <symbol>，其余民族回落到现有渐变：

const ETH_ART = { e20:'#art-she', e39:'#art-tj', e40:'#art-nu', e43:'#art-ew' };
const artId = ETH_ART[g.key];
const cov = artId
  ? `<svg viewBox="0 0 320 320" style="width:100%;height:100%;display:block"><use href="${artId}"/></svg>`
  : `<span style="...">${esc(g.name)}${st}</span>`;   // 其他民族保持原渐变
  1. 把本稿的四张 <symbol id="art-*"> 与图腾 <symbol id="t-*"> 整段搬进 mountainriverechoes.html 顶部已有的 SVG <defs> 区（那里已有 30 个图标 symbol）
  2. 改 ethCardHTML()，四个民族 key 走插画，其余走渐变
  3. 歌单详情页头图（.pl-head .cov）复用同一张插画，加 preserveAspectRatio="xMidYMid slice" 裁成横幅
  4. 侧栏 .logo-icon 与播放条封面图形，按当前民族切换图腾
  5. 其余民族（汉族民间小调等）保持原有金色／红色渐变默认皮肤，完全不受影响

插画为纯矢量 SVG，四张合计约 12 KB，随模板进包；无网络请求、无位图资源、任意分辨率清晰。
